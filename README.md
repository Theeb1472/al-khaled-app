# مكتبة الخالد الرقمية | AL KHALED Digital Books

هذه نسخة احتياطية من **النصوص الرقمية** للأحاديث والتفسير في تطبيق «الخالد». 
المستودع الأساسي يُستخدم لنشر APK عبر GitHub Releases؛ لذلك وُضعت الكتب في الفرع المنفصل `digital-library` حفاظًا على الفرع `main`.

## مصادر المواد والتوثيق

- الأحاديث الخمسة: [fawazahmed0/hadith-api](https://github.com/fawazahmed0/hadith-api) (Arabic editions; انظر ترخيص المشروع).
- بيانات التفاسير الستة: [Quranpedia.net](https://quranpedia.net/api-docs) و[التحميلات الرقمية](https://api.quranpedia.net/dumps) — **البيانات أصلًا من Quranpedia.net**، مع الإحالة إلى شروط الاستعمال الخاصة بها.
- تفسير القرطبي: [spa5k/tafsir_api](https://github.com/spa5k/tafsir_api).

هذه طبعات رقمية مستقلة عن كتب PDF المصورة التي وفرها مالك التطبيق. وجود النص على الإنترنت لا يعني أن كل طبعاته أو الحقوق التابعة له متاحة بلا قيود. يجب التحقق من حقوق إعادة التوزيع، خصوصًا الأعمال الحديثة، قبل نشر التطبيق للجمهور.

## البنية

`books/` : ملفات JSON.gz مضغوطة لعدد 12 كتابًا، في 21 ملفًا إجمالًا لأن تفسير القرطبي موزع على 10 أجزاء حسب السور.

`books/manifest.json` : قائمة بكل الملفات، وأحجامها، وبصمات SHA-256.

تُستخدم نسخ GitHub كـ **مصدر احتياطي** فقط عند تعذر الوصول إلى Supabase؛ وتُخزَّن الكتب محليًا على الهاتف بعد تنزيلها.

## المزامنة

سير عمل `.github/workflows/mirror-digital-books.yml` يسحب الملفات عبر روابط Supabase العامة ويتحقق من سلامة GZIP وJSON ثم يحدّث المجلد `books/` دون تخزين مفاتيح خاصة.
